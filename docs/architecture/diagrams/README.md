# Architecture diagrams

Maintained diagrams are embedded with their owning documents:

- [Current implemented architecture](../current-implementation.md): installed
  topology, simulated/real boundaries and current platform behavior.
- [High-Level Architecture](../high-level-architecture.md): accepted design and
  expanded obligations, not a claim that every design case is implemented.
- [Architecture flows](../demo-scenario-architecture-flows.md): lifecycle,
  authority and data flow.

Update the owning document and accepted inputs together; do not introduce a
second current diagram baseline. Private reference material is not public source.

The earlier two-SP authoring model remains available as an immutable
[Draw.io source](https://github.com/alexmaninblack/aosedge-sdv-demo/blob/cc75541f255f3d2fb0fd670053687ebe406c37ee/docs/architecture/diagrams/aosedge-demo-hla-authoring-reference.drawio)
and [PNG export](https://github.com/alexmaninblack/aosedge-sdv-demo/blob/cc75541f255f3d2fb0fd670053687ebe406c37ee/docs/architecture/diagrams/aosedge-demo-hla-authoring-reference.png).
They are visual provenance, not the current deployment diagram.
