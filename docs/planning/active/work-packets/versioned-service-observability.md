## Motion and state separation

Return to road stops motion, clears held inputs, repositions at an appropriate
lane-aligned location, waits for settled physical evidence, and leaves the
car stationary in Manual. Autopilot requires explicit subsequent selection.
Preserve Unit/service/model/advisory state. Mark scene discontinuity so a
teleport or interrupted capture cannot produce a fictitious assessment.
Verify collision/off-road, occupied position, busy/double-click and uncertain
command cases through the existing serialized control protocol.

Maneuvers are real stimuli, not guaranteed warnings. Backend Reset is an
independent model action, not an implicit precondition of vehicle recovery or
service update. Reuse the conditional native scenario action where possible.

### P5 bounded command wiring

The native app receives a trusted Demo Control argv prefix, as with its existing
external-link helper, and invokes only `simulation return-to-road --target test`
or `simulation exercise brake|tire --target test`, without a shell. The existing
environment writer and source-operation journal serialize these actions. Native
heartbeat/telemetry workers stay alive; held keys are cleared and ordinary drive
commands disabled while a scene action is pending. Safe Stop remains available.

Return to road reuses the same authenticated orchestration socket, operation
identity and safe_stop/reset/manual_ready/release_manual sequence. The existing
tick owner validates the configured known-good spawn for lane alignment and
dynamic vehicle/walker/prop clearance before moving the ego; no nearest-lane
search or second tick owner is added. Post-reset road placement and advancing
stationary frames must be confirmed before stationary Manual release. A known
rejected placement releases only into confirmed Safe Stop; uncertain operations
remain held and are reconciled by the same journal identity, never reset again
blindly. Busy/double clicks cannot start competing actions. Existing reset
generation/discontinuity facts accompany actual physical relocation.

The controller's local status adds bounded recovery capability, road-placement
and rejection facts; these are not new vehicle telemetry or service inputs.
No source reassignment, advisory/model reset, Cloud call or VM/service restart
is part of this scene action. P7 must separately verify that interrupted capture
and physical discontinuity produce no spurious product assessment.
