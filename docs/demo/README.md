# Demo Documentation

This directory owns audience-visible scenarios, storyboards, presenter flows,
and original demo visual assets. These documents describe what the audience
sees; they do not redefine the system architecture.

[Staged Post-SOP Brake Health Demo Scenarios 1.0](staged-post-sop-brake-health-demo-scenarios.md)
is the accepted audience-visible baseline. It defines the five-stage
`G0 -> G1 -> G2 -> G3 -> G4` capability evolution without authorizing
architecture mapping or implementation.

The corresponding
[Demo Scenario Architecture Flows 0.1](../architecture/demo-scenario-architecture-flows.md)
are now under review. They map the accepted story to architecture elements and
gaps but do not yet authorize requirements or implementation.

No storyboard or presenter flow is accepted yet. Those are separate next
steps after architecture mapping.
