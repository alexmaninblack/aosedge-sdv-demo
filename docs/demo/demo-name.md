# Demo name

Status: accepted by the operator on 20 September 2026.

The audience-facing name of this demonstration is:

**AosEdge Platform - SDV Lab**

Use this exact spelling and capitalization in the planned demo video's title
and new presentation materials. The name identifies the overall SDV lab,
not only the Brake Health and Tire Health scenarios or the Presenter app.

This records a naming decision only. It does not rename repositories, packages,
Cloud objects or existing application/window titles, change branding assets,
or alter any demo flow. Applying the name to the running UI is a separate
implementation step. Historical documents and mockups keep their original titles.
