# Alternative icon families for mockup 2.7

Status: visual exploration only, 9 September 2026.

These generated concept boards propose different icon silhouettes and visual
languages, rather than new backgrounds for the existing outline set. They show
eight roles and a static in-context sample of team navigation, backend cards
and the Domain Controller.

- [A — Automotive pictograms](a-automotive-pictograms.png): filled automotive
  silhouettes with negative-space detail.
- [B — Technical miniatures](b-technical-miniatures.png): dimensional equipment
  and software-module miniatures.
- [C — Two-tone cutouts](c-two-tone-cutouts.png): simplified shapes in two
  coordinated blue tones.

The boards are image-generation sketches, not production icon assets or exact
pixel-level mockup exports. Small-size optical simplification and an actual
in-mockup review are required after selection. The generated examples do not
approve changes to layout, flows, roles or backend semantics. CARLA and the
existing 2.7 mockup remain unchanged.

Created with the built-in image generation tool; the complete prompt set is
in [generation-prompts.md](generation-prompts.md).

## B2 — Automotive miniatures

[View the revised board](b2-automotive-miniatures.png).

The user requested hardware that visually belongs in a production vehicle:
automotive ECU enclosures, mounting ears and keyed harness connectors, rather
than home-router or generic desktop equipment. B2 distinguishes the larger
aluminum domain computer from the compact central gateway. The component and
service symbols remain dimensional software metaphors, not additional ECUs.

The in-vehicle gateway role was cross-checked against
[Bosch's central gateway description](https://www.bosch-mobility.com/en/solutions/vehicle-computer/central-gateway/).
This is not a reproduction of a Bosch product or a claim of automotive-grade
certification. The board is a generated art-direction sketch; repeat-symbol
consistency and small-size detail still need normalization for production assets.

Generated with the built-in image tool using B as the edit target. The exact
brief is retained in [b2-generation-prompt.md](b2-generation-prompt.md).
No mockup, application code, behavior or live system was changed.
