## Purpose

This register provides the one-row-per-rule forward and reverse traceability
required by `UI-TRC-001`. It links each stable interaction rule to its actual
upstream owner, audience-visible surface and mandatory acceptance case without
copying requirement prose. `DESIGNED` means only that the accepted design and
verification route exist; it does not mean implemented or qualified.

## Change Rules

- A new interaction rule receives a new stable `UI-INT-*` ID, one row here and
  at least one mandatory `UI-AT-*` case in the same change.
- Editorial clarification preserves the existing row and links.
- A changed upstream owner, surface or observable verdict updates this register
  in the same Level-B cascade; copied parent requirement text is prohibited.
- `IMPLEMENTED` and `QUALIFIED` may be set only from the corresponding code and
  evidence gates; a mockup or screenshot cannot advance the status.
