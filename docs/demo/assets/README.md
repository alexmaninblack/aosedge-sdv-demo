# Demo Assets

Only original, license-cleared demo diagrams and visual assets belong here.
Keep editable sources together with their exported forms.

The live Presenter owns its icons and
[selected B2 artwork](../../../apps/presenter-ui/src/assets/studio/automotive-b2.png).
The selected artwork was generated with the built-in image-generation tool;
the original [art-direction and generation record](https://github.com/alexmaninblack/aosedge-sdv-demo/blob/d14e837c4cca30d8d9ebe83df996974b92c46f3b/docs/demo/mockups/icon-concepts-2-7/README.md)
remains in Git. Alternative concept boards, duplicate icons, old screenshots
and standalone HTML prototypes are no longer part of the source checkout.
The [public visual inventory](../../../workspace/public-visual-assets.json)
retains exact content checks for the shipped assets and architecture reference.

Do not commit customer or partner presentation screenshots, private
correspondence, credentials, proprietary material, or files from the local
`Human input` directory.
